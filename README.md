# Titanic Survival Prediction - Data Cleaning

## Features Covered
- Data loading and exploratory inspection (`.info()`, `.describe()`)
- Imputation of missing numerical values (`Age`, `Fare`) using median
- Categorical imputation for `Embarked`
- Label Encoding for binary features (`Sex`)
- One-Hot Encoding for multi-class nominal features (`Embarked`)
- Age distribution visualization with Seaborn
- Exported cleaned dataset to `titanic_cleaned.csv`
